# 🎖️ Game Reward System

## 🧠 Overview
Mysteries are more satisfying when the player is *seen*, *celebrated*, and *elevated*. This system tracks progress, achievements, and player rank to make every action feel meaningful.

Rewards can also serve as gentle nudges for discovery, enhancing immersion while subtly guiding the user through complexity.

---

## 🪙 Core Mechanics

### ✅ Points System
- Earn points for:
  - Correct deductions
  - Unique clue discoveries
  - Insightful interrogations
  - Completing sub-goals or chapters
  - Emotional intelligence (e.g. calming a suspect)

- Lose points for:
  - Accusing the wrong suspect
  - Repeating ineffective actions
  - Ignoring critical evidence

### 🎁 Clue Shop
- Spend points on:
  - Hints (“Something’s off about Claudette…”)
  - Expanded dialogue options
  - Memory recall (previous AI statements)
  - Hidden lore (worldbuilding unlocks)

---

## 🧑‍✈️ Rank System
Players advance through a themed mystery rank ladder:

| Rank | Requirements |
|------|--------------|
| Beat Cop | Starting rank |
| Rookie Detective | Solve 1 case or gather 100 pts |
| Field Investigator | Uncover 5 secrets |
| Inspector | Solve 3 advanced cases |
| Chief of Detectives | Solve perfect case with no mistakes |

Each rank unlocks:
- Custom case files
- Special badge graphics / in-game flair
- Advanced mode mysteries

---

## 💎 Bonus Systems

### 🧬 Emotional Echoes
- Some characters will *remember* how they were treated
- Earn “Grace Points” for kindness, empathy, tact
- Unlock alternate endings or loyalty-based dialogue

### 📜 Lore Collectibles
- Hidden diary pages, newspaper clippings, ghost echoes
- Add flavor and lore to the Velvet Lily world
- Completion unlocks dreamlike meta-narrative sequences
